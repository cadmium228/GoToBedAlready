# Desktop UI, v0.2

Источники рекомендаций:
- UI-UX-PRO-MAX: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- Anthropic frontend-design: https://github.com/anthropics/skills/tree/main/skills/frontend-design

UI-UX-PRO-MAX прочитан; локальный поиск `compact desktop utility restrained` предложил минимализм. Рекомендации про hero, CTA, маркетинговые секции и внешние шрифты отклонены: это небольшая Windows-утилита, не лендинг. Из frontend-design применены ограничение декоративного текста, отказ от нумерации без реальных шагов, единая иерархия и проверка дизайна по скриншотам.

## План и проверка против запроса

- Одна колонка в окне 560 × 620; без навигации и декоративной оболочки.
- Фон `#1e2023`, поля `#292c30`, границы `#44484f`, текст `#edf0f3`, вторичный текст `#b5bac3`, действие `#b4cbe9`.
- Segoe UI Variable / Segoe UI: системная Windows-типографика, без скачивания шрифтов; 26 px заголовок, 14 px органы управления, 12 px пояснения.
- Процесс → задержка → два параметра питания → действие. Заголовки и значения выровнены влево, числовая задержка справа.
- Прогресс появляется только в запущенной сессии. Ошибки не скрываются ради минимализма; нейтральные служебные сообщения, журнал и лозунги убраны.
- Нет лун, орбит, градиентов, карточек с метриками, бейджей localhost, левой панели и footer.
