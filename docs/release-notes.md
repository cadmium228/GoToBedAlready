# GoToBedAlready v0.2.0 — Windows Preview

Предварительный релиз. Это по-прежнему экспериментальная утилита: проверяйте
назначение выбранного индикатора и поведение выключения на своём ПК.

## Что нового

- Собственное окно **WinForms + WebView2** вместо вкладки браузера. Консоль не
  открывается; закрытие окна отменяет наблюдение и освобождает запросы питания.
- Управление питанием: гашение экрана при наблюдении, повторное гашение после
  десяти секунд без ввода, отключение автоматического сна и гашения экрана.
- Список процессов текущей пользовательской сессии, включая процессы без
  собственного окна. Окна потомков учитываются при чтении прогресса.
- Дополнительный источник прогресса — нативный `msctls_progress32` через
  ограниченные по времени Win32-вызовы; UI Automation и кнопка панели задач
  сохранены.
- Связь `SocialClubHelper` → `Launcher` проверяется по дереву PID и времени
  запуска, а не только по имени файла.
- Диагностика прогресса сохраняется в JSON-файл по кнопке.

## Проверки

- Linux и Windows CI: `go test -race -cover ./...`, `go vet ./...`,
  `node --check web/app.js`, `gofmt`.
- Windows CI: компиляция C# WebView2-хоста, чтение реального WPF `ProgressBar`
  через UI Automation (25% → 100%), список безоконного процесса, синтаксис
  PowerShell, запуск собранной demo-сборки.
- Оба Windows-архива собираются кросс-компиляцией без CGO.

Физическое гашение монитора, работа окна WebView2 на конкретном ПК и
совместимость с реальными лаунчерами (Steam, Rockstar Games Launcher и другими)
автоматически не проверяются. Публичного универсального API для чтения чужого
прогресса в Windows нет; если индикатор недоступен, выключение блокируется.

## Требования

- Windows 10/11 x64 или ARM64.
- Microsoft Edge WebView2 Runtime.
- Windows PowerShell 5.1 и .NET Framework 4.8 (4.8.1 для ARM64).

## Архивы

- `GoToBedAlready-v0.2.0-windows-amd64.zip`
- `GoToBedAlready-v0.2.0-windows-arm64.zip`
- `SHA256SUMS.txt`

Распакуйте архив целиком: каталоги `web`, `scripts` и `runtime` должны лежать
рядом с `GoToBedAlready.exe`. EXE не подписан Authenticode, поэтому SmartScreen
может показать предупреждение.

Релиз v0.1.0 не изменялся.
